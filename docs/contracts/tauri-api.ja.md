# Tauri API 契約

Svelte アプリケーションは Rust アプリケーション層のクライアントです。TS/TLV の解析、
ARIB のデコード、映像のレンダリング、変換セマンティクスの決定は行いません。

公開コマンド面は [`../backend-contract.md`](../backend-contract.md) に列挙しています。
本ページでは責務別に分類します。

- 検査とエクスポート：`inspect_source`、`start_export`、`cancel_export`、`pause_export`、`resume_export`
- 永続化ジョブと復旧：`create_job`、`list_jobs`、`get_job`、ジョブ制御、診断、成果物、チェックポイント、キュー制御
- 設定と DRCS：設定、言語パック、DRCS レポートの読み込み
- プレビューとタイムライン：ネイティブプレビュー制御、archive レンダリング、再生マッピング、上限のあるタイムラインウィンドウ

コマンドは上限のあるデータと安定したエラーコードを返さなければなりません。UI は選択肢から
成果物を推測したり、バックエンドにない能力を捏造したりしてはなりません。

## コマンド面の凍結

現在のコマンド面は収束段階にあります。基盤モデルが安定するまでは、既存クエリの一時的な
派生を増やすべきではありません。次にタイムラインクエリを統合する際は、さらに
`get_timeline_*` を追加せず、mode、時間範囲、filter を明示する単一のパラメーター化された
`query_timeline` リクエストを優先します。この移行でも、応答上限、archive cursor の意味、
安定したエラーコード、および連携したフロントエンド契約更新を維持する必要があります。
