> 本檔案是 `frontend-macos27-migration-matrix.md` 的譯文。簡體中文檔案是唯一具權威性的規範；英語、日語與繁體中文（臺灣）版本僅為譯文。任何歧義或衝突一律僅以簡體中文檔案為準。

本檔案是 ResubWinny 前端重寫的交付契約。它在遷移視覺實現期間凍結產品介面。
只有當一個畫面的現有行為、文案、狀態、無障礙功能與效能門檻全部在真實的 Tauri
應用程式中透過時，該畫面才算完成。

## 來源優先順序

1. 行為與材質放置以 Apple Human Interface Guidelines 為準。
2. 控制項尺寸與狀態以 Apple 官方 macOS 27 UI Kit 為準。
3. 已批準的 Figma 畫框，包括 `Task State / Timeline Indexing / 1280x820`。
4. 功能、文案、資料與資訊結構以現有應用程式為準。
5. 外部參考僅用於視覺實現研究。

任何未經批準的徽標、品牌顏色、內容功能或替代資訊架構均不屬於本次遷移。

## 平臺規則

- 標題欄不顯示標題文字。標題欄與側邊欄在視覺上應呈現為同一種材質。
- 視窗控制項使用 `macos-traffic-lights`，並保留其最小布局區域。
- 生產控制項對映到官方 UI Kit 變體；沒有相應產品需求時，不得新增僅供視覺使用的變體。
- UI 文字優先引用已安裝的 SF Pro，並使用適合區域的系統後援字型。不得再分發 Apple UI Kit 中嵌入的字型。
- 不得在 Windows 包中再分發 Apple 限制使用的符號。Windows 資源須保留已批準的語義、描邊與光學尺寸對映。
- Liquid Glass 僅限用於導航層和控制項層。影片、時間線、表格、表單、日誌及其他內容表面保持實色。
- 原生 mpv 表面及其祖先元素絕不得應用 `filter`、`backdrop-filter`、`transform` 或 WebView 透明度。
- 視覺驗收使用已打包的 Tauri/WebView2 應用程式，而非瀏覽器開發頁面。

設定類別導航屬於導航層，可以使用 Liquid Glass。設定組、預覽、執行時詳情、
“關於”中繼資料、許可證搜尋、許可證列表、通知及完整許可證文字均為內容表面，須保持

Liquid Glass 控制項處理；內容容器使用現有的實色表面與邊框令牌。

## 推進門檻

每個垂直切片都必須透過全部四項門檻，方可擴大工作範圍：

1. **契約：** 保留現有命令、文案、狀態與四種區域設定。
2. **視覺：** 在相同視口下與官方 Kit 及已批準的 Figma 進行比較。
3. **互動：** 鍵盤、指標、焦點、減少動態效果及緊湊佈局全部透過。
4. **執行時：** 在真實 Tauri/WebView2 中驗證，原生預覽不得發生回歸。

對於“設定”、“關於”與“許可證”，視覺評審還須驗證：玻璃效果僅出現在類別導航、
選單與控制項上；可讀內容絕不應用 `filter` 或 `backdrop-filter`；在常規寬度下類別
標簽保持可見；緊湊佈局不得將類別列表變成按鈕墻。強制顏色、靜態玻璃及減少動態
效果後援是釋出要求，而非可選潤色。

最終效能目標為：面板與玻璃互動 p95 低於 20 ms；互動期間不得有超過 50 ms 的前端
長任務；不得有空閑動畫幀迴圈；初始 gzip JavaScript 增長低於 10%；CSS gzip 不超過
15 KB。
