> 本文書は `frontend-macos27-migration-matrix.md` の訳文です。簡体字中国語文書のみが唯一の権威ある仕様であり、英語版、日本語版、繁体字中国語（台湾）版は翻訳にすぎません。曖昧さまたは矛盾がある場合は、簡体字中国語文書のみを基準とします。

本文書は ResubWinny フロントエンド書き換えのデリバリー契約です。視覚実装の移行中、製品サーフェスを凍結します。
画面が完了したとみなされるのは、既存の振る舞い、文言、状態、アクセシビリティ、性能ゲートがすべて実際の Tauri
アプリケーションで合格した場合に限ります。

## ソースの優先順位

1. 振る舞いとマテリアル配置は Apple Human Interface Guidelines に従います。
2. コントロールの寸法と状態は Apple 公式 macOS 27 UI Kit に従います。
3. `Task State / Timeline Indexing / 1280x820` を含む、承認済み Figma フレーム。
4. 機能、文言、データ、情報構造は既存アプリケーションに従います。
5. 外部参照は光学的実装の調査にのみ使用します。

未承認のロゴ、ブランドカラー、コンテンツ機能、代替情報アーキテクチャは、いずれも本移行の対象外です。

## プラットフォーム規則

- タイトルバーにタイトルテキストを表示しません。タイトルバーとサイドバーは一体のマテリアルとして見える必要があります。
- ウィンドウコントロールは `macos-traffic-lights` を使用し、最小レイアウト領域を維持します。
- 本番コントロールは公式 UI Kit バリアントに対応させます。対応する製品要件なしに視覚専用バリアントを追加してはなりません。
- UI テキストはインストール済み SF Pro を最優先で参照し、地域に適したシステムフォールバックを使用します。Apple UI Kit に埋め込まれたフォントを再配布してはなりません。
- Apple が使用を制限するシンボルを Windows パッケージで再配布してはなりません。Windows アセットは承認済みの意味、ストローク、光学サイズの対応を維持します。
- Liquid Glass はナビゲーション層とコントロール層に限定します。動画、タイムライン、表、フォーム、ログ、その他のコンテンツサーフェスは不透明のままにします。
- ネイティブ mpv サーフェスとその祖先要素には、`filter`、`backdrop-filter`、`transform`、WebView の透明化を決して適用してはなりません。
- 視覚受け入れには、ブラウザー開発ページではなく、パッケージ化済み Tauri/WebView2 アプリケーションを使用します。

## 昇格ゲート

すべての垂直スライスは、作業範囲を拡大する前に4つのゲートすべてに合格しなければなりません。

1. **契約：** 既存のコマンド、文言、状態、4つのロケールを維持します。
2. **視覚：** 同一ビューポートで公式 Kit および承認済み Figma と比較します。
3. **インタラクション：** キーボード、ポインター、フォーカス、視差効果を減らす設定、コンパクトレイアウトが合格します。
4. **ランタイム：** 実際の Tauri/WebView2 で検証し、ネイティブプレビューにリグレッションがないこと。

「設定」、「情報」、「ライセンス」では、視覚レビューでさらに、ガラス効果がカテゴリーのナビゲーション、
メニュー、コントロールにのみ現れること、可読コンテンツに `filter` または `backdrop-filter` を決して適用しないこと、通常幅でカテゴリー
ラベルが見えること、コンパクトレイアウトでカテゴリー一覧をボタンの壁にしないことを検証します。強制カラー、静的ガラス、視差効果を減らす
フォールバックはリリース要件であり、任意の仕上げではありません。

最終性能目標は、パネルとガラスのインタラクション p95 が 20 ms 未満、インタラクション中に 50 ms を超えるフロントエンド
ロングタスクなし、アイドル時アニメーションフレームループなし、初期 gzip JavaScript 増加率 10% 未満、CSS gzip は
15 KB 以下です。
