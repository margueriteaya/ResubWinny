# サポート対象のツールチェーン

[简体中文](toolchain-policy.md) · [繁體中文](toolchain-policy.zh-TW.md) · [日本語](toolchain-policy.ja.md) · [English](toolchain-policy.en.md)

> **規範に関する注記：** 簡体字中国語版が唯一の正式な情報源です。他言語版は同期された翻訳であり、文言に曖昧さや矛盾がある場合は、簡体字中国語版が優先されます。

このリポジトリでは、`rust-toolchain.toml` によって Rust を `1.97.1` に固定しています。CI とローカルのリリース候補ビルドでは、バージョンを指定しない `stable` ではなく、このファイルを使用しなければなりません。同じツールチェーンの Rustfmt と Clippy もゲートの一部です。

デスクトップフロントエンドは Node.js 22 LTS を、コミット済みの npm ロックファイルとともにサポートします。検証とパッケージングには、制約のない依存関係の更新ではなく `npm ci` を使用してください。より新しい Node バージョンがローカルで動作する場合もありますが、リリースの基準ではありません。

Windows 11 x86-64 は、Alpha パッケージおよびネイティブプレビューの受け入れプラットフォームです。Worker、Tauri のコンパイル、フロントエンドのチェックは引き続き Windows、macOS、Linux で行いますが、macOS/Linux のネイティブプレビューバックエンドは延期されています。

ツールチェーンのアップグレードは、意図的な依存関係の変更です。以下が必要です。

1. リリースノートと互換性のレビュー。
2. Worker、デスクトップ、フロントエンド、ファジングのコンパイルゲート。
3. 無関係なパッケージ変更を伴わないロックファイルのレビュー。
4. Windows のパッケージ済みプレビューと長時間サンプルの回帰テスト。
5. CI、この文書、コントリビューター向け手順を 1 つの変更で更新すること。

どのアプリケーションコンポーネントも、実行時にコンパイラー、パッケージマネージャー、ビルドツールをインストールしてはなりません。
